# let’s go! bot

Telegram-MVP для компаний друзей: идеи → голосование → дата → подтверждения → фотография → ачивка.

## Что уже работает

- создание компании и приглашение по deep-link;
- идеи с оценками сложности, бюджета и длительности от 1 до 5;
- открытый или анонимный автор;
- голосование с возможностью изменить голос;
- назначение даты после завершения голосования;
- напоминания за день, в момент встречи и после неё;
- подтверждение выполнения каждым участником;
- обязательная фотография;
- выдача ачивки только при выполнении обоих условий.

## Локальный запуск

```bash
cd bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Создайте бота через [@BotFather](https://t.me/BotFather), вставьте токен в `.env`, затем из корня проекта запустите `python3 -m bot.main`.

По умолчанию данные хранятся в `bot/data/lets_go.db`. Для MVP этого достаточно; перед публичным масштабированием базу следует перенести в PostgreSQL.

## Тесты

```bash
python3 -m unittest discover -s bot/tests
```

## Docker

Из корня проекта:

```bash
docker compose --env-file bot/.env -f bot/compose.yml up -d --build
```

Данные хранятся в отдельном Docker volume `lets_go_data`.
